# Ivy+ Learning Library

SÓCRATES DS uses **Ivy+** as a product label for a curated set of official learning resources from institutions such as MIT, Harvard and Stanford. MIT and Stanford are not members of the Ivy League; the label is intentionally broader than the athletic conference.

## Goal

The library is not a bookmark dump. A source enters the Campus only when it satisfies four requirements:

1. official university source;
2. meaningful relevance to one of the seven courses;
3. access and difficulty are labeled explicitly;
4. the source supports a cognitive action such as recall, derivation, problem solving, implementation, transfer or research design.

## Copyright / source policy

SÓCRATES DS stores metadata, mappings and official URLs. It does **not** mirror university PDFs, videos, notes or assignments by default.

The original material remains hosted by MIT, Harvard, Stanford or the relevant provider and remains subject to the license/terms shown at the source.

## Priority semantics

- **Core** — recommended as a parallel course or primary reference.
- **Recommended** — supports the local course at high value without duplicating all of it.
- **Extension** — go deeper after the local concept is understood.
- **Benchmark** — useful for comparing scope and rigor, but not presented as open learning material if only a syllabus is public.

## Recommendation roadmap

The next learning-intelligence increment should use the resource-to-concept mappings to recommend a source only when a learner has a specific need, for example:

```text
weak prerequisite
    ↓
identify concept
    ↓
select official resource mapped to concept
    ↓
choose one lecture / problem / note
    ↓
active recall or problem solving
    ↓
new evidence
```

The library should never recommend “take another entire course” when a 20-minute targeted intervention is sufficient.
